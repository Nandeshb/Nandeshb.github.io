# Nandesh Mulge — Portfolio

Static recruiter-focused portfolio built with HTML, CSS, and vanilla JavaScript.

## Run locally

Open this folder in VS Code and run `index.html` with the Live Server extension, or open `index.html` directly in a browser.

## Deploy with GitHub Pages

1. Create a public repository named `<your-github-username>.github.io`.
2. Upload the contents of this folder so `index.html` is at the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save.

## Notes

- The profile photo is in `assets/profile.jpg`.
- The resume is in `assets/Nandesh_Mulge_Resume.pdf`.
- The site uses no animation libraries or build step.
- Desktop pointer effects are disabled on coarse/touch pointers.
- Touch feedback clears on release/cancel and is cancelled when movement indicates scrolling.
- `prefers-reduced-motion` is supported.
